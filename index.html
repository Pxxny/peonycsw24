🗂️ นำเข้า / ส่งออก Cardbox

เก็บ Cardbox ชุดปัจจุบันไว้เป็นไฟล์ JSON แล้วแทนที่ด้วยชุดใหม่ได้ พออยากกลับมาเรียนชุดเดิมค่อย Import กลับเข้ามา (การ Import จะแทนที่ Cardbox ทั้งหมดที่มีอยู่)

💡 Import จะลบ Cardbox ปัจจุบันทิ้งก่อน — แนะนำให้ Export เก็บไว้ก่อนเสมอถ้ายังไม่อยากเสียชุดที่กำลังเรียนอยู่

📦 Group คำศัพท์ (บันทึกไว้หลายชุด)

ติ๊กเลือกคำที่ต้องการในรายการ Cardbox ด้านบนก่อน แล้วกดปุ่มนี้เพื่อคัดลอกเฉพาะคำที่เลือกไว้เก็บเป็น "Group" (ไม่ลบของเดิม) ตั้งชื่อได้ พอเรียนชุดนี้เสร็จแล้วอยากเปลี่ยนไปชุดใหม่ก็เพิ่ม Group ไว้ก่อน แล้วค่อยโหลดกลับมาทีหลังได้

ตัวกรองขั้นสูง

Pattern: ใช้ _ หรือ ? แทนตัวอักษรใดก็ได้ในตำแหน่งนั้น (ความยาวของ Pattern ต้องตรงกับคำ) · Rack: คำจะต้องประกอบขึ้นได้จากตัวอักษรที่ระบุเท่านั้น (ใช้แต่ละตัวได้ไม่เกินจำนวนที่มี ใส่ ? เป็น Blank ใช้แทนตัวอักษรใดก็ได้)

สัดส่วนสระ = จำนวนสระ (A E I O U) ÷ ความยาวคำ × 100 — ใช้หาคำที่มีสระเยอะ/น้อยเป็นพิเศษ

🕹️ Minigame

ฝึกพิมพ์คำศัพท์ให้เร็วและแม่นยำ หรือท้าทายตัวเองหาคำทั้งหมดจาก Rack ตัวอักษร

🏃 Word Marathon

โหมดฝึกความอึด แรงบันดาลใจจากนักกีฬาทีมชาติที่นั่งซ้อม Marathon 7 ตัวอักษรยาวๆ หลายชั่วโมง — เลือกความยาวคำตั้งแต่ 5-12 ตัวอักษร ตั้งเวลารวมได้ตามใจ พร้อมจุด Checkpoint ให้พักเป็นระยะ

ของจริงบางคนซ้อมกัน 7 ชั่วโมง (420 นาที) — ปรับได้ตามต้องการ
ตั้งเป็น 0 ถ้าไม่ต้องการ Checkpoint อัตโนมัติ (ยังกด "พักตอนนี้" เองได้เสมอ)

⚡ Time Attack Marathon

ตอบต่อเนื่องหลายรอบแบบจับเวลาสั้นๆ ต่อรอบ — แต่ละรอบจะสลับโจทย์ระหว่าง Anagram / Rack / คำจาก Cardbox แบบสุ่ม ตอบให้ทันเวลาก่อนรอบจะหมดเวลาแล้วข้ามไปรอบถัดไปอัตโนมัติ

ถ้า Cardbox ว่างหรือไม่ติ๊กประเภทไหนไว้เลย ระบบจะสลับไปใช้ประเภทที่เหลืออัตโนมัติ

🔀 Alphagram Blitz

ไล่ทวนคำศัพท์ยาว 7 ตัวขึ้นไปแบบ Alphagram (ตัวอักษรเรียง A→Z) ทีละชุด — บางชุดมีคำตอบที่ถูกได้มากกว่า 1 คำ ต้องหาให้ครบทุกคำถึงจะผ่านข้อนั้น เลือกจับเวลาแบบ Time Attack หรือเล่นแบบไม่จับเวลาก็ได้

⌨️ พิมพ์ศัพท์ Random

พิมพ์คำที่ปรากฏให้ตรงทุกตัวอักษร เปิดโหมดเข้มงวดถ้าอยากให้พิมพ์ผิดแล้วเริ่มรอบใหม่ทันที

โหมดนี้ใช้ความยาวเดียว และเอาคำ "ทุกคำ" ที่มีความยาวนั้นมาให้พิมพ์ทั้งหมด (ไม่จำกัดจำนวน)
เช่น "BN" จะเจอ BEN, BANANAS ฯลฯ · ถ้าใส่ตัวอักษรซ้ำ เช่น "NN" คำนั้นต้องมี N อย่างน้อย 2 ตัว
